# Architecture Decision Records

Architecture Decision Records (ADRs) document key decisions for our Keycloak
solution, including the context, alternatives considered, and consequences.

- [Database selection](database-selection.md) — PostgreSQL as the database for Keycloak.
- [PostgreSQL hosting](postgresql-hosting.md) — Azure Managed PostgreSQL as the hosting solution.
- [SCIM implementation](scim-server-implementation.md) — A custom SCIM 2.0 provider, flais-scim-server, for user provisioning.
