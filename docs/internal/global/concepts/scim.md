## What is SCIM?

SCIM (System for Cross-domain Identity Management) is a standard for provisioning
identities between systems. Provisioning includes creating, updating, and deleting
users and supplying user attributes.

SCIM handles identity lifecycle management, not interactive authentication.
Identity providers handle authentication. Keycloak resolves identities and issues
tokens during login.
